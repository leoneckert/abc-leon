click on these two links and closely observe how the URL in the top of your browser changes

link to secondPage.html

link to /secondPage.html


😭 the problem 🫨

the second link we clicked was absolute and took us out of the current project folder to the very root of our web server:

        
    ...github.io/secondPage.html

but this page doesn't even exist


📝 why this matters for us 🤓

your website will be hosted on https://browsercircus.com/your-name/your-port

in your <head></head>, your socket.io library might be included like this: 

        
    <script src="/socket.io/socket.io.js"></script>

once your website is on the server, it will try to get the library from: 

        
    https://browsercircus.com/socket.io/socket.io.js

however, your server file serves the library on:

        
    https://browsercircus.com/your-name/your-port/socket.io/socket.io.js

🌟 the solution / don't forget to do this: 🌟

to make sure the library is loaded, remove the / before socket.io/...

like so:

        
    <script src="socket.io/socket.io.js"></script>
